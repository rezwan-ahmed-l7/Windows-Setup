# About The Repository

This repository documents my Windows 11 customization journey and contains the configuration files, themes, and setup resources I use to build my personal development environment.

It includes customized Windows Terminal settings, PowerShell profiles, Fastfetch configurations, custom ASCII artwork, cursor themes, and other desktop personalization resources.
